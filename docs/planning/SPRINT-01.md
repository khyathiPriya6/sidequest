# Sprint 01 — Foundation
**Capacity:** 8–10 hours, beginning November 6, 2026.
**Goal:** Git repository, running React/Vite web app, Spring Boot health API, PostgreSQL in Docker, and web-to-API connection.

## Committed tasks
- SQ-001 Repository structure and contributor documentation (45 min)
- SQ-002 Spring Boot API and health endpoint + test (90 min)
- SQ-003 React + TypeScript Vite app and basic layout (75 min)
- SQ-004 Web health dashboard consuming API and handling connection failure (90 min)
- SQ-005 PostgreSQL Docker Compose with local-only config (90 min)
- SQ-006 API conventions and OpenAPI proposal (60 min)
- SQ-007 Review, run tests, and document local setup (90 min)

## Out of scope
Quest CRUD, auth, AWS, mobile, AI, Kubernetes, Redis, production deployment.

## Definition of Done
- API health endpoint returns JSON.
- Web displays API status (or understandable error).
- PostgreSQL starts via Compose; credentials not committed.
- Health controller has an automated test.
- README documents setup, commands and known gaps.
- One reviewable PR per issue.

## Weekly retrospective
Record: issue IDs, completed work, test evidence, decisions, blockers, what the agent did, what I personally understand, next priorities.
